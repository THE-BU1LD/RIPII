# RIPII paper review checklist

## Automated / evidence gates

- [x] Full LaTeX manuscript exists.
- [x] Bibliography keys referenced by the manuscript all exist.
- [x] Braces and begin/end environments are structurally balanced.
- [x] Primary numerical claims mapped to committed evidence surfaces.
- [x] Negative and no-advance verdicts preserved.
- [x] Historical and repaired-source evidence kept separate.
- [ ] Current manuscript source PDF build passes.
- [ ] Rendered PDF artifact visually inspected.
- [ ] No unresolved LaTeX warnings that change meaning or hide content.

## Scientific review

- [x] Abstract numbers checked against PAPER_EVIDENCE_MAP.md.
- [x] Pilot-v2 table checked against research/results/pilot_v2/summary.json.
- [x] World-v3 means checked against the retained capsule.
- [x] Paired intervals/p-values checked against world_v3_convergence_statistics.json.
- [x] Conditional-coupling wording checked against the prospective protocol.
- [x] NRI section remains labeled external-simulator development evidence.
- [x] Objective-study language does not imply asymptotic optimization claims.
- [x] Gradient diagnostic described as diagnostic, not causal.
- [x] Repaired 0.2 and RIPII-MR do not rewrite historical studies.
- [x] External confirmation remains explicitly unexecuted.
- [x] No SOTA, universal hierarchy-failure, or algorithmic-novelty language.

## Human release gates

- [ ] Final author list and order.
- [ ] Contributions statement.
- [ ] Affiliations.
- [ ] Funding and conflicts.
- [ ] Software/data license decision.
- [ ] Venue selected.
- [ ] Venue-specific page/style/anonymity requirements applied.
- [ ] AI-use disclosure checked against venue policy.
- [ ] Final PDF visually reviewed page by page.
- [ ] Release/submission receipt retained before calling the paper submitted.

## Do not do

- Do not rerun or retune an experiment merely to improve manuscript numbers.
- Do not replace a failed frozen gate with a later exploratory metric.
- Do not open external/confirmatory test data before its protocol is frozen and authorized.
- Do not infer authorship, affiliation, funding, or license from repository history.
